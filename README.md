# Mod_SedimentadorConPlacas
Modelo tridimensional de un sedimentador con placas inclinadas (lamelas), con plano de simetría en la sección central (plano XZ). La unidad CE~586 Precipitación y Floculación (GUNT), disponible en el Centro Interdisciplinario de Investigaciones del Agua y el Ambiente (CIIAAA-UNLP).
